Documentos protocolos sobre el uso de OpenFoam y herramientas asociadas a este, los documentos fueron desrrollados para la materia Dinámica Computacional de Fluidos de la Universidad Nacional de Colombia
* Protocolo 02: función *probes* aplicado a *cavity* 2D
* Protocolo 03: densificación de malla usando *simpleGrading* aplicado a *cavity* 3D
* Protocolo 04: preprocesamiento y simulación de flujo en un canal usando *pimpleFoam*
* Protocolo 05: uso de *snappyHexMesh* para simulación de flujo alrededor de una esfera
